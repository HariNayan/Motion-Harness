# motion-lib

A small deterministic motion toolkit for HyperFrames. Two files, copied into each project's `assets/` by `mh new` (refresh with `node harness/mh.mjs sync-lib`):

- `mh-motion.js` — `window.MH` (needs GSAP loaded first)
- `mh-motion.css` — design tokens (`--mh-*`), type classes, restrained background systems, 12-col grid, graphic atoms

```html
<script src="https://cdn.jsdelivr.net/npm/gsap@3.14.2/dist/gsap.min.js"></script>
<link rel="stylesheet" href="assets/mh-motion.css" />
<link rel="stylesheet" href="assets/mh-tokens.css" />   <!-- generated by `mh tokens` from direction.json -->
<script src="assets/mh-motion.js"></script>
```

## Conventions

- Every primitive is `MH.<group>.<name>(tl, target, opts)` and **returns the end time in seconds**, so you can chain: `let t = MH.type.reveal(tl, "#h", {at: .3}); MH.graphic.draw(tl, "#line", {at: t - .2});`
- `tl` is the scene's own paused GSAP timeline; `at` is scene-local seconds. Durations in `opts` are seconds; `stagger` options are **frames** (converted with `MH.cfg.fps`, default 30).
- Everything uses `fromTo`, so scrubbing back is exact. No timers, no randomness, no `repeat:-1`.
- **Ease roles, not ease strings:** `enter`, `exit`, `move`, `snap`, `soft`, `draw` (`MH.cfg.ease.*`). Pass a role name or a raw GSAP ease. Override per project with `MH.configure({ease:{enter:"expo.out"}, dur:{base:20}})`.
- Tween only what a primitive documents; do not put a CSS `transform` on an element GSAP transforms.
- Studio editability: `MH.type.*` splits text into spans at build time (so `data-var-text` on that element will not survive the split). Keep editable copy variables for text you do not split.

## Timing — `MH.timing`, `MH.F`

| call | does |
| --- | --- |
| `MH.F(frames)` | frames → seconds |
| `MH.timing.stagger(i, frames)` | delay for the i-th sibling |
| `MH.timing.window(start, dur, inFrames, outFrames)` | `{inAt, outAt, outDur}`: an exit that lands just before a clip's end |
| `MH.timing.snap(t, cues, tol=.12)` | snap a time to the nearest cue (beat/word start) |

## Typography — `MH.type`

| call | options | use for | avoid |
| --- | --- | --- | --- |
| `split(el, mode, mask)` | `mode` words/chars; returns unit elements | custom choreography | chars on long lines (cost, readability) |
| `reveal(tl, el, o)` | `at, mode, mask=true, from(up/down/left/right), stagger, dur, ease, distance, tracking:{from,to}, skip` | **editorial headlines**: masked word/char rise. `skip:1` leaves the first word static so frame 0 already shows the subject | body paragraphs; anything read for more than ~7 words |
| `tracking(tl, el, o)` | `from, to, dur` | a title that "settles" (wide → tight) | text being read while it moves |
| `punch(tl, el, o)` | `scale, color` | one word that must land (meaning, not decoration) | more than one per scene |
| `lines(tl, container, o)` | `y, stagger, dur` | short supporting lines you wrote as children | headline-level text |
| `exit(tl, el, o)` | `y, dur, stagger` | quick exit after the text has been read | scene ends that a transition already covers |

## Transitions — `MH.transition`

Put the primitive in the **incoming** scene and let hosts overlap by the transition length (the gate allows up to +0.75 s of overlap per host).

| call | does | note |
| --- | --- | --- |
| `wipe(tl, el, {dir})` | clip-path edge travels left/right/up/down | the calm default; pick the axis the reader's eye travels |
| `iris(tl, el, {x,y})` | circular reveal from a point | when the point means something (a dot becomes the next scene) |
| `slats(tl, container)` | children (full-width bars) shrink to reveal | rhythmic; bars are your markup, colour them from tokens |
| `match(tl, el, fromEl)` | FLIP: `el` flies from where `fromEl` sits | one shape continues across two layouts (same composition only) |
| `dip(tl, plate, {frames})` | 2-frame flash plate | hit on a beat; use sparingly |

Pick **one** primary transition language per film and allow one motivated exception.

## Graphics — `MH.graphic`

| call | options | use for |
| --- | --- | --- |
| `draw(tl, svgPath, o)` | `at, dur` | stroke-drawn lines, orbits, waves (needs `getTotalLength`) |
| `counter(tl, el, o)` | `from,to,decimals,prefix,suffix,sep` | a number the viewer should wait for |
| `bars(tl, container, o)` | children carry `data-value`; `max, axis x/y, stagger` | real bar data on a shared baseline/scale |
| `callout(tl, line, label, o)` | `origin, dx` | a label tied to a part of a diagram |
| `rules(tl, container, o)` | children grow along x | grid/table rules |
| `form(tl, el, o)` | `scaleFrom, rotFrom, origin` | a geometric form arriving |

## Images — `MH.image`

| call | use |
| --- | --- |
| `push(tl, img, o)` | slow controlled scale/drift inside an `overflow:hidden` frame |
| `parallax(tl, [{el, depth}], o)` | layered depth; `depth` 0..1, nearest moves most |
| `cropOpen(tl, frame, o)` | tight crop opens to the wider framing |

Footage/image grading, grain and blur go through `hyperframes media-treatment` (see the media-use skill), never CSS filters.

## Audio-aware — `MH.audio`

Cue data must be **inlined**: `node harness/mh.mjs cues <slug> --from beats.json|transcript.json` writes `assets/mh-cues.js` (`window.MH_CUES = {beats, words, hits}`); load it before scene scripts.

| call | does |
| --- | --- |
| `beatsIn(sceneStart, a, b)` | beat times (scene-local) inside [a,b) |
| `wordAt(word, sceneStart, nth)` | spoken word start (scene-local) or `null` |
| `pulse(tl, el, sceneStart, a, b, o)` | scale pulse on each beat in a window |
| `onWord(tl, word, sceneStart, fn, fallback, nth)` | land `fn(time)` on a spoken word, or on `fallback` when no transcript |

Only use with real timing data. A pulse on every beat is emphasis, not decoration: one element per scene.

## Backgrounds — `MH.bg` and CSS

`MH.bg.drift(tl, el)` (±2% ambient drift) and `MH.bg.sweep(tl, el)` (low-contrast directional wash). CSS classes on a full-bleed child (never the composition root): `mh-bg--solid`, `--grid`, `--hatch`, `--dots`, `--split`, `--split-v`, `--wash`, plus `.mh-grain` (static SVG noise at 6%). Intensity via `--mh-bg-amount`. There is deliberately no glow, bloom, mesh gradient or particle class.

## Layout — `MH.layout`, CSS

`MH.layout.safe(w,h)` returns the 90% action and 80% title boxes; `MH.layout.verticalUI` holds the 9:16 keep-outs (top 250, bottom 420, right 120). CSS: `.mh-safe`, `.mh-cols` + `.mh-c-N` (12-col grid), `.mh-display`, `.mh-body`, `.mh-eyebrow`, `.mh-accent`, `.mh-rule`, `.mh-bar`, `.mh-bar--accent`.

## World layer — `mh-world.js` / `mh-world.css` (dense, reference-class films)

Added after studying a dense reference edit. The rules it taught (not its artwork): a rich film has **one persistent world**, **persistent chrome**, and **a hero object per beat** — never text alone. Load after `mh-motion.js`:

```html
<link rel="stylesheet" href="assets/mh-world.css" /> <script src="assets/mh-world.js"></script>
```
Preset: `node harness/mh.mjs preset <slug> night-sky` writes the matching design system (palette incl. `panel`, `cold`, `cloud`, sky tokens; Montserrat / Poppins / JetBrains Mono; accent rule; density `rich`). `mh tokens` then emits every palette key as `--mh-<key>`. Object materials (planet gradients etc.) belong in `:root` tokens in `index.html`, not hard-coded in scenes.

**Architecture (mount order = z-index):** persistent layer compositions mounted for the whole film (`bg-sky`, `transitions`, `hud`, `captions`), plus one scene composition per beat. List the layer ids in `storyboard.json` as `"layers": [...]` so the gate treats them as layers, not scenes. Always give builders a **unique container id** (`#sky-box`), never `#root` (every composition has one).

| builder | what it makes | notes |
| --- | --- | --- |
| `W.sky(box, {seed, bands, motes, light})` + `W.skyMotion(tl, sky, dur)` | gradient sky, soft directional light, parallax cloud bands, drifting motes (seeded) | one per film; the light is a single wash, not a glow effect |
| `W.hud(box, {title, end, waypoints:[{t,label}]}).animate(tl)` | title, route strip with progress, waypoint diamonds, "now" chip | waypoint `t` in film seconds |
| `W.callout(box, {x,y,lx,ly,w,kicker,value,note,tone})` + `calloutIn/Out(tl, g, t)` | anchor dot → ring → leader → panel | keep panel text short; label hold ≥ 0.5 s + 0.3 s/word |
| `W.gauge(box, {size,min,max,a0,a1,ticks,unit,label,decimals,bands})` + `gaugeTo(tl,g,from,to,at,dur)` | dial gauge with needle and readout | keep `label` ≤ ~12 chars; use `a0:-120,a1:120` to leave room |
| `W.path(box, {d,size,traveler,stroke,dash})` + `W.travel(tl,p,{at,dur,from,to,orient,ease})` | guide path, traveller riding it, trail drawn behind | flight path, orbit, tide curve, route |
| `W.stage3d(box)`, `W.cube`, `W.cubeFlow`, `W.floor`, `W.orbit3d`, `W.tilt3d` | CSS-3D stage, particle cube, floor plane, camera move, 3D card entrance | no WebGL; seekable. Keep camera sway small if 2D callouts anchor to 3D objects |
| `W.drum(box, digits, {unit})` + `drumTo` | odometer readout | for numbers that change |
| `W.captions.build(box, words, o)` + `.animate(tl, built)` | karaoke caption groups, active-word underline, no overlapping groups | needs word timing: real (`hyperframes transcribe` → `mh cues`) or clearly labelled synthetic |
| `W.rng(seed)`, `W.el(tag, attrs, parent)` | seeded PRNG, DOM/SVG builder | `fill`/`stroke` `var(...)` values are applied as styles |

Caveats found in real frames: scripted-built layers (sky, HUD, captions) are not editable as HTML in Studio — keep their data (waypoints, words) in the layer file; a cloud-bank transition must rest far enough off-screen that no puff shows (see `ex-world-tides/compositions/transitions.html`); 2D callouts anchored to a swaying 3D object drift with the camera.
